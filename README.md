# Top 10 des films MovieLens avec Hive et Spark

Projet final du module *Introduction au Big Data & Écosystème Hadoop* (L3 IA, ISM Dakar).

Objectif : trouver les 10 films les mieux notés du jeu de données MovieLens (ml-latest),
avec un nombre minimal de notes, d'abord avec Hive puis avec Spark, et comparer les deux outils.
